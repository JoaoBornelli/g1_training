**Goal:** criar `g1_training/vault/`, um vault Obsidian em árvore de abordagens, e mover para ele `docs/memoria/` e a memória `g1-*`/`mjlab-*`/`bfm-*`.

**Architecture:** notas Markdown com frontmatter (`tipo`, `pai`, `estado`, `verificado`). A pasta repete a árvore. Páginas de frente e a Home usam Dataview. Um script `vault/checa.py` garante que nenhuma nota fica solta.

**Tech Stack:** Obsidian, Dataview, Python 3 (só stdlib) para a checagem.

**Spec:** `specs/2026-10-05-vault-g1-design.md`

## Global Constraints

- Lugar: `g1_training/vault/`, versionado no git do repo.
- `tipo` ∈ {frente, abordagem, achado, decisao, pendencia, estudo}.
- `estado` ∈ {em-desenho, ativa, validada, rejeitada, parada, superada, aberta, fechada}.
- `pai` obrigatório, exceto na raiz `G1.md`. O pai precisa existir no vault.
- `estado: superada` exige `superada_por`.
- Nada é apagado: obsoleto vira `superada`.
- Memória do Claude fica com uma linha + caminho no vault.
- Git: o usuário faz o commit (memória `feedback-quem-executa`). Os passos de commit são propostas de mensagem.

## Review Focus

1. Nota com `pai` que aponta para um nome inexistente → `checa.py` acusa.
2. Dois arquivos com o mesmo nome em pastas diferentes → link `[[x]]` ambíguo; `checa.py` acusa.
3. Link antigo para `docs/memoria/...` em spec, relatório ou memória → reescrito; `grep` volta vazio.
4. Nota migrada perde conteúdo → contagem de palavras antes e depois por arquivo.

```python
# vault/checa.py
"""Checa o vault: toda nota tem tipo, estado e um pai que existe."""
import re
import sys
from collections import Counter
from pathlib import Path

TIPOS = {"frente", "abordagem", "achado", "decisao", "pendencia", "estudo"}
ESTADOS = {"em-desenho", "ativa", "validada", "rejeitada", "parada",
           "superada", "aberta", "fechada"}
RAIZ = "G1"
IGNORA = {".obsidian", "_templates"}


def _frontmatter(texto):
    m = re.match(r"---\n(.*?)\n---", texto, re.S)
    if not m:
        return {}
    return dict(re.findall(r"^(\w+):\s*(.*)$", m.group(1), re.M))


def _alvo(valor):
    m = re.search(r"\[\[([^\]|#]+)", valor or "")
    return m.group(1).strip() if m else None


def checa(raiz: Path) -> list[str]:
    notas = [p for p in raiz.rglob("*.md")
             if not IGNORA & set(p.relative_to(raiz).parts)
             and p.name not in {"CLAUDE.md", "inbox.md", "Home.md"}]
    nomes = Counter(p.stem for p in notas)
    erros = [f"nome duplicado: {n}" for n, c in nomes.items() if c > 1]
    for p in notas:
        fm, n = _frontmatter(p.read_text()), p.stem
        if fm.get("tipo") not in TIPOS:
            erros.append(f"{n}: tipo {fm.get('tipo')!r} inválido")
        if fm.get("estado") not in ESTADOS:
            erros.append(f"{n}: estado {fm.get('estado')!r} inválido")
        if fm.get("estado") == "superada" and not _alvo(fm.get("superada_por")):
            erros.append(f"{n}: superada sem superada_por")
        if n == RAIZ and p.parent == raiz:
            continue
        pai = _alvo(fm.get("pai"))
        if not pai:
            erros.append(f"{n}: sem pai")
        elif pai not in nomes:
            erros.append(f"{n}: pai inexistente [[{pai}]]")
    return erros


if __name__ == "__main__":
    erros = checa(Path(sys.argv[1] if len(sys.argv) > 1 else Path(__file__).parent))
    print("\n".join(erros) or "vault ok")
    sys.exit(1 if erros else 0)
```
